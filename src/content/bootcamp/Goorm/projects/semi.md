## 플랫폼 산업

### 플랫폼이란?

공급자와 수요자를 연결해 **네트워크 효과**를 통해 가치를 창출하는 비즈니스 모델.
직접 제품을 만들지 않고, 참여자들이 상호작용할 수 있는 **생태계(ecosystem)** 자체를 운영함.

> 파이프라인 비즈니스(제조 → 판매)와 달리, 플랫폼은 양면 또는 다면 시장을 형성한다.

| **O2O 플랫폼** | 온라인 수요-오프라인 공급 연결 | 배달의민족, 야놀자, Uber |
| **AI 플랫폼** | 개발자-AI 모델/인프라 연결 | OpenAI API, HuggingFace |

### 플랫폼의 핵심 원리

#### 네트워크 효과 (Network Effect)
- **직접 네트워크 효과**: 사용자가 늘수록 기존 사용자에게도 가치 증가 (카카오톡)
- **간접 네트워크 효과**: 한쪽 참여자가 늘면 반대쪽 가치 증가 (앱스토어: 앱↑ → 유저↑)
- 임계점(Critical Mass)을 넘으면 자기강화 루프 형성 → **승자독식** 구조

#### 양면 시장 (Two-sided Market)
- 플랫폼은 두 그룹 이상을 동시에 유치해야 작동
- 보통 한쪽(공급자)에게 무료/저가 → 반대쪽(수요자)에서 수익화
- 예) Google: 사용자 무료 검색 → 광고주에게 과금

#### 수익 모델
| 방식 | 설명 | 예시 |
|------|------|------|
| 중개 수수료 | 거래액의 일정 % | 쿠팡, 배달의민족 |
| 광고 | 노출·클릭 기반 과금 | Google, Meta, Naver |
| 구독 | 월정액 프리미엄 | YouTube Premium, Slack |
| SaaS | 기업 대상 소프트웨어 사용료 | AWS, Salesforce |
| 데이터 판매 | 집계 데이터 B2B 제공 | Nielsen, 카드사 |

##### 디지털 유산 문제

- 한국에는 디지털 유산에 관한 **별도 법제가 없음** (2024년 기준)
- 응답자 **65.6%가 디지털 유산 개념 자체를 인지하지 못함** (2025년 1월 설문)
- 그러나 **63%는 디지털 유산의 가족 상속에 찬성**, 상속 희망 항목 1위: 사진·영상(75.6%)
- SNS·이메일·구독 서비스·가상자산 등은 별도 원스톱 수단 없음 → 각각 개별 해지 요청 필요
- 암호화폐는 개인 키 분실 시 영구 소멸 위험
- 출처: [한국정보통신정책연구원(KISDI) 「디지털 유산 처리방안 연구」](https://www.korea.kr/archive/expDocView.do?docId=32395)

## 사후 행정 처리 서비스 기획

### 문제 검증

#### 1. 서비스 실현 가능성 검증

##### 시장 규모

- 연간 사망자 약 35~37만 명 × 유족 평균 2~3명 = **잠재 수요자 약 70~110만 명/년**
- 2040년 사망자 50만 명 이상 전망 → 시장 규모 지속 확대
- 고독사 연 3,900명 이상: 유족이 없거나 연락이 끊긴 경우 → 공공·기업 위탁 수요 존재

##### 기술적 실현 가능성

| 기능 | 실현 방법 | 난이도 |
|------|-----------|--------|
| 사후 행정 체크리스트 제공 | 자체 DB + 정부 안내 연동 | 낮음 |
| 기관별 신청 가이드 | 정부24·각 기관 링크 안내 | 낮음 |
| 금융 계좌 조회 | 안심상속 원스톱 서비스 API 연동 | 중간 |
| 서류 자동 작성 | 사망자 정보 입력 기반 템플릿 생성 | 중간 |
| 디지털 유산 정리 | 각 플랫폼 API·해지 대행 | 높음 |
| 상속세 신고 지원 | 세무사 연계 또는 AI 초안 작성 | 높음 |

##### 법적 실현 가능성

- 사망신고, 금융 해지 등 **본인(상속인) 명의 처리 원칙** → 대행 시 위임장 필수
- 개인정보보호법상 고인의 정보 접근은 **상속인 증명 후 가능**
- 디지털 유산 관련 법제 미비 → 서비스 범위 제한 필요 (현재는 가이드 역할 중심이 현실적)
- 법무사·세무사 업무 영역 침해 없도록 **전문가 연계 모델** 설계 필요

##### 경쟁 현황

| 유형 | 서비스 | 한계 |
|------|--------|------|
| 공공 | 정부24 안심상속 원스톱 | 조회만 가능, 실제 처리·가이드 없음 |
| 공공 | 찾기쉬운 생활법령정보 | 정보 제공에 그침, UX 불친절 |
| 민간 | 장례식장 부대서비스 | 장례 이후 연속성 없음 |
| 민간 | 법무사·세무사 사무소 | 고비용, 접근성 낮음 |

> **결론**: 전 과정을 통합해 안내·대행하는 민간 서비스는 사실상 공백 상태 → **진입 가능성 높음**

#### 2. 인터뷰 질문 설계

> 사후처리 **경험자** (유족으로서 행정 처리를 직접 해본 사람)와 **비경험자** (아직 경험 없는 성인)를 구분하여 진행

##### 공통 질문 (경험자·비경험자 모두)

1. 사후 행정 처리에 어떤 절차가 있는지 알고 계신가요? (인지도 측정)
2. 가족이 사망했을 때 행정 처리를 혼자 할 수 있을 것 같으신가요?
3. 사후 행정 처리를 도와주는 서비스가 있다면 이용할 의향이 있으신가요?
4. 그런 서비스에 비용을 지불한다면 어느 정도가 적절하다고 생각하시나요?
5. 서비스를 신뢰하기 위해 가장 중요한 요소는 무엇인가요? (보안, 전문성, 브랜드 등)

**[경험 파악]**

5. 행정 처리를 완료하기까지 총 얼마나 걸렸나요?
6. 비용(법무사, 세무사, 서류 발급 등)은 얼마나 발생했나요?
7. 가장 도움이 됐던 정보나 서비스는 무엇이었나요?

**[감정·맥락]**

8. 처리 과정에서 가장 힘든 감정적 순간은 언제였나요?

**[서비스 니즈]**

10. 그 당시 어떤 서비스가 있었다면 가장 도움이 됐을 것 같나요?
11. 대행 서비스가 있었다면 어떤 부분을 맡기고 싶으셨나요?
